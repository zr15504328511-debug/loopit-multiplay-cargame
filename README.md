# Loopit Multiplayer Car Game

可直接运行的浏览器弹弓赛车。使用 JavaScript、WebGL2 和 Web Audio，无运行时 npm 依赖。

默认进入可自由驾驶的 3D 大厅：开车驶入五个实体弹弓选择地图，随后拖拽蓄力、弹射飞行，结束后自动返回大厅。当前为最多 20 人的本地演示，本人以外的玩家由 AI 回放驱动，尚未连接多人服务器。

## 运行

需要 Node.js 20 或以上，以及支持 WebGL2 的浏览器。

```sh
npm start
```

打开 <http://127.0.0.1:4173>。Windows 也可以双击 `Start-Game.cmd`；运行 `Stop-Game.ps1` 停止该启动器创建的服务。无需安装依赖或构建。

更换端口：PowerShell 中运行 `$env:PORT=4174; npm start`，或使用 `Start-Game.ps1 -Port 4174`。开发服务器仅监听本机地址，只提供游戏页面、源码和运行素材。

## 玩法

- 大厅：W/S 前进、倒车，A/D 转向；支持方向键、触屏摇杆、拖动画面环视和滚轮缩放。
- 选图：直接开进弹弓。五张地图依次解锁，必须本人到达前一图终点；锁住的入口有挡杆。
- 发射：向下拖动后松手，或按住空格蓄力后松开。飞行中左右调整方向，W/S 调整空中姿态。
- 道具：出发前在设置里选辣椒或滑翔翼，每次飞行只能使用一次；释放弹弓后按空格或道具按钮使用。
- 升级：初始 500 金币，大厅底部升级车辆、弹弓、收益；飞行结束奖励自动入账。金币和升级跨地图保留。
- 玩家：七种车型和不同颜色区分身份，大厅车顶显示昵称；飞行侧栏最多显示三个小头像。
- 排行：左上奖杯查看各地图的房间最高纪录，刷新纪录后在对应位置立旗。查看排行不改变当前赛道。

昵称、人数、道具、金币、升级、纪录和解锁保存在当前浏览器。更换设备或清理浏览器数据不会自动同步。`?mode=solo` 保留独立的单人练习和战役模式。

## 代码与检查

```sh
npm test
```

包含资源引用检查、游戏物理、场景碰撞、大厅驾驶、逐图解锁、道具、金币升级、排行数据及存档回归；报告写入忽略提交的 `output/`。

主要目录：

| 目录 | 内容 |
| --- | --- |
| `src/` | 游戏逻辑、WebGL 渲染、物理、大厅与界面 |
| `public/assets/` | 五张地图、车辆、音频、字体、材质、碰撞及 AI 回放 |
| `tools/` | 本地服务器及运行时回归检查 |
| `docs/` | 开发交接、规则与测试说明 |

详见 [开发交接](docs/DEVELOPMENT.md)、[当前规则](docs/GAMEPLAY.md) 和 [验证说明](docs/TESTING.md)。素材及许可边界见 [NOTICE.md](NOTICE.md)。
