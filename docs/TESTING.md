# 验证说明

## 自动检查

运行 `npm test`，无需安装额外依赖。脚本会先创建 `output/`，再顺序执行资源引用、物理、存档、场景碰撞、大厅驾驶、道具和升级回归。任何一项失败即返回非零状态。

`npm run verify:assets` 单独验证资源文件及代码中的静态引用。新增运行素材后应更新引用，避免仅在开发目录中存在的隐式依赖。

## 浏览器交互

启动本地服务后，用独立浏览器配置运行 `tools/browser-room-v3.js` 的 Playwright CLI `run-code` 脚本。该脚本会清空其浏览器中的大厅存档，因此不要在个人游戏存档的浏览器会话中运行。

```sh
npx --yes --package @playwright/cli playwright-cli -s=loopit-qa open http://127.0.0.1:4173
npx --yes --package @playwright/cli playwright-cli -s=loopit-qa run-code --filename=tools/browser-room-v3.js
```

交互从零金币、裸车架开始，通过真实驾驶/弹射赚取金币，再实际购买三项各一次，验证价格30→37/37/45、一级属性、收益倍率、20人状态、排行榜及刷新恢复。另用明确的独立存档夹具验证旧档备份迁移、下一图载入重置与弹弓余数、下一轮清零；这些夹具不是驾驶通关证据。20行排行榜用独立UI夹具验证滚动，不把夹具成绩写入游戏。

额外手工检查：第一张地图的水面、雪场障碍、不同地图的材质、锁住入口的碰撞，以及手机摇杆松手复位。测试成功不意味着真实网络同步或完整刚体物理已经实现。

浏览器截图与测试报告只写入 `output/`，不纳入版本库。
