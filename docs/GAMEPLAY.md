# 当前规则

大厅容量 1–20 人，默认 8 人；本人以外的参与者为本地 AI。游戏尚未接入真实联机服务。

## 地图与参与者

地图顺序为 Savannah → Ski Resort → West Coast → Formula → Rainbow Road。必须本人完成前一图才开放下一图。玩家通过驾驶进入实体弹弓选择赛道；未开放入口有实体挡杆。

每名玩家有稳定的车型、颜色、昵称和小头像。大厅显示车顶昵称；飞行栏仅显示本人及最多两个正在飞行的对手头像，其他参与者用细刻度。最高纪录保存在各地图中，刷新纪录后旗帜移动到新的最远位置。

## 升级与奖励

新档从 0 金币、0 升级开始，大厅与单人 Campaign 共用 `save.js` 和 `campaign.js` 的规则。每次购买只增加一次当前/累计计数；首关三项第一次均为 30 金币。车辆从无轮车架开始。

设地图索引 `L=0…4`，本关该项购买次数为 `n`，累计收益购买次数为 `t`：

- 车辆、弹弓价格：`trunc(30 × 3.25^L × (1.25 + 0.05×L)^n)`。首关依次为 30、37、46、58、73、91……。
- 收益价格：`trunc(30 × 1.5^t)`，依次为 30、45、67、101、151、227……。
- 收益倍率：`2^(L + floor(t/5)) × (1 + 0.1×(t%5))`。第一关累计 0/5/10/15 次对应 1/2/4/8 倍。

计算沿用共享函数的 float32 舍入边界，最终截断小数。取消大厅原先的 3/5/10 次购买上限；车辆和弹弓最终物理档位仍会饱和，继续购买不会无限增加动力。资金不足、飞行中或价格超出可表示范围时不能购买。

车辆在 5/10/15/20/25 次获得普通车轮、完整车身、升级轮、专业套件、最终减阻，阶段内逐次改变阻力；弹弓按每次购买对应的力度推进。大厅卡片显示累计购买次数+1，以及五格阶段进度。

自然失败的距离奖励为 `trunc(最远距离 × 收益倍率)`，成功使用 `trunc(终点世界Z × 收益倍率)`；不再加演示版基础10、距离×0.3或通关额外75。主动退出不奖励，同次结束只发一次；返回大厅自动到账。

## 跨地图与存档

开进新解锁地图代替战役的 Next 操作：该关三项当前购买次数清零，金币和三项累计购买次数保留。弹弓实际力度计数为 `本关次数 + (累计次数 - 本关次数)%5`，保留上一关不足一组的余数；收益价格和倍率使用累计收益次数。

为了保留大厅的自由选图，重访已完成地图会恢复该图在本轮的升级，不反复清除已购部件；金币和累计次数仍全房间共享。五图完成后，第一张地图入口用于开始下一轮：金币、累计次数和各图升级清零，下一轮重新逐图解锁。历史排行榜纪录和身份保留。原线性战役没有自由重访地图，这部分是大厅适配。

旧演示存档先按原 JSON 备份在独立 localStorage 键中，再迁移余额、昵称、纪录和解锁。旧车辆/弹弓跳档转换为已有物理等级对应的逐级购买次数；收益保留已购买次数，随后使用当前倍率。其他地图首次进入时使用零级车辆。迁移仅一次，不重新赠送金币；新档始终从零开始。

## 道具

每次出发前选择一种，弹弓释放后可用一次，无途中拾取或叠加。

- 辣椒：水平速度增加 25 米/秒，提示持续 1.2 秒；实际速度受限速、阻力和碰撞影响。
- 滑翔翼：5 秒内重力为正常的 28%，激活时向上速度至少 1 米/秒，不增加水平速度。

玩家从零级开始成长；AI 仍使用满级演示回放。单人模式 `?mode=solo` 与大厅各自保存进度；Campaign 与大厅共享升级计算，道具和自由重访流程仍不同。
